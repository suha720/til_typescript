# 함수(function)

- 데이터를 가공해서 원하는 결과를 자동으로 만들어주는 기계(기능)

## 1. 기본 형태

```ts
function 동사이름(재료: 데이터타입): 결과데이터종류 {
  // 하고 싶은말
  return 결과;
}

동사이름(재료);

function 함수명(매개변수: 자료형): 리턴자료형 {
  // 하고 싶은말
  return 리턴값;
}

함수명(인자);


function 함수명(parameter: type): returnType {
  // 하고 싶은말
  return returnValue;
}

함수명(argument);

```

- 동일한 기능을 다른 가람에게 주어야 한다면?
